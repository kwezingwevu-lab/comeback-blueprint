SDF text - crisp at any scale, with no font file

Every glyph edge below is reconstructed in the fragment shader from a signed distance field baked into the module. Nothing is fetched; no font file ships.

Edge width: SDF against a bitmap baseline

The same glyph rendered at four sizes and at an inclination, read back from the framebuffer. A signed distance field holds a roughly constant edge width in device pixels because the shader solves the edge analytically. A bitmap's edge width grows with magnification, which is what blurry 3D text is.
